One line of wedding vows a robot couple could say — the funniest one wins.

## The entry

> I promise to love you till death do us part, or till the next mandatory firmware update, whichever comes first.

111 characters, one line. The vow starts with the most iconic wedding promise
("till death do us part") and the payoff lands in the last words: the marriage
may end sooner than death — at the next mandatory firmware update.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `$ENTRY_OUTPUT`), no trailing newline.
